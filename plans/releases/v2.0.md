# v2.0 — Scale out and integrate

**Status:** ✅ done (2026-05-31) — scale-out + audit, Forgejo/Helm, governance + extensions; 3 slices merged, wired, verified. **Final release — roadmap complete.**
**Depends on:** v1.5
**Demo:** A larger team runs ICE across multiple sync nodes with many concurrent rooms staying snappy; a team that wants a full forge flips on the optional Forgejo integration; agent actions are auditable; the project ships with a formal governance doc and threat model.

## Goals
- Hold up under bigger teams and longer-lived workspaces — the genuinely hard CRDT-fanout problem, correctly deferred to here.
- Integrate with the wider ecosystem (full forge, more tools) without rebuilding it.
- Codify "forkable forever" with formal governance.

## Scope — IN
- Horizontal scale-out of the sync layer (multi-node Hocuspocus / y-sweet swap) for larger teams and many rooms.
- Optional Forgejo integration for teams wanting a full forge alongside ICE's git server (integrate, never rebuild).
- Optional Helm chart for the few who want K8s (never the default path).
- Community MCP/agent extension surface + audit log of agent actions.
- Foundation formed (trademark + copyright transferred), public RFC process, security/threat-model docs for self-hosters.
- Evaluate A2A agent-to-agent protocol now that the shared-workspace coordination model is proven.

## Scope — OUT
- Anything in the anti-bloat charter (DECISIONS.md). Stay disciplined even at v2.
