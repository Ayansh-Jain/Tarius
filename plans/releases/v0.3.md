# v0.3 — Git comes home

**Status:** ✅ done (2026-05-31) — 3 worktree slices (git server, convergence, web tree) merged, wired, verified e2e.
**Depends on:** v0.1
**Demo:** From a plain terminal, `git clone http://<your-ice-server>/<room>.git`, commit, `git push` — and the change appears live in the room's editor. Create/rename files in the UI and they show for everyone. The CRDT↔git seam flushes the live doc to disk and commits cleanly.

## Goals
- Make Pillar 4 literally true: clone/push/pull to a git server that ships in the box, no external forge.
- Establish the **CRDT↔git boundary as a single owned module** (the architectural law, ARCHITECTURE.md).
- Give the workspace a real multi-file shape.

## Scope — IN
- Bundled smart-HTTP git server (`isomorphic-git` + `node git-http-backend`) over bare repos; clone/push/pull from any git client.
- SSH keys / tokens for git auth.
- Per-room repos with a synced file tree (create/rename/delete) shared across participants.
- Live doc ↔ working-tree sync with explicit flush-to-disk + commit semantics (the owned `convergence` module).
- Branches + commit history surfaced in-app.
- Hardened compose self-host path.

## Scope — OUT
- Forge UI (issues/PRs/review) — never (optional Forgejo at v2). Agents — v0.5.

## Notes
- This release lands the seam **before any agent** (v0.5). The convergence module is the most-tested code in the repo.
- **The data-loss trap, caught & guarded:** `loadRoomFromGit` prunes/overwrites to match HEAD, which would erase uncommitted edits on reload. Wiring in `realtime.ts` `onLoadDocument` therefore only seeds git→doc when the doc is **empty** (SQLite holds live state); git never overwrites live edits. (See ADR-000.)
- Single-port server (REST + `/sync`) + a **dedicated internal git port** (`ICE_GIT_PORT`, default `PORT+1`) — git smart-HTTP and Hono have different streaming semantics, so separate listeners is the robust choice.
- C-webtree left some headless-smoke helper files under `apps/web/src/lib/*.smoke.ts` + loader shims (excluded from build via tsconfig). Harmless; candidate for a cleanup pass.
