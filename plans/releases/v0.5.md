# v0.5 — Your first AI teammate

**Status:** ✅ done (2026-05-31) — agent host + ACP↔Yjs adapter, shared terminal, web agent UI; merged, wired, verified e2e.
**Depends on:** v0.3 (the CRDT↔git seam must exist first)
**Demo:** Open a room, type `@agent refactor this function` in the agent panel. Watch the agent join as a named participant and edit *the same buffer you're in* — its changes appear with a distinct color/attribution. A destructive action pauses for your **approve/interrupt**. One click undoes the agent's change. The shared terminal shows the command output to everyone.

## Goals
- Land Pillar 1 single-agent: the agent types INTO the same buffer, as a participant with its own cursor.
- Solve correctness for ONE writer-agent before ever touching concurrency.
- Ship the trust layer that makes a shared-workspace agent safe rather than a footgun.

## Scope — IN
- ACP client: connect ONE agent (Claude Code / Codex / Gemini), BYO-key, model-agnostic, out-of-process.
- Agent as a named participant; every edit an **origin-tagged Yjs transaction** (visually distinct, attributable, one-click undo).
- Agent chat panel docked to the editor; can reference files and lines.
- Live tool-call / proposed-diff stream with **approve / interrupt** before destructive actions land.
- Built-in agent tools (read/write files via the doc, run terminal) + shared server-side terminal (`node-pty` + `xterm.js`).
- Per-workspace branch with agent edits attributed in commits.

## Scope — OUT
- Multiple agents / orchestrator / permission policies (→ v1.5). Voice/chat (→ v1.0).
