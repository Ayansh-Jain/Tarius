# v1.0 — Code with friends, out loud

**Status:** ✅ done (2026-05-31) — voice + chat + in-UI git/rollback/preview + hardening; 4 slices merged, wired, verified.
**Depends on:** v0.5
**Demo:** A squad joins a room, hops into a **voice huddle**, chats in a thread with a code-snippet embed, edits live together with an agent, reviews the agent's branch in an **in-app diff + merge gate**, rolls back one change with a click, and sees the running app in the **shared preview** — all on their own `docker compose` server.

## Goals
- Complete Pillar 2: voice + chat co-located with the live code.
- Reach "a squad can live in it" — polished, hardened, documented self-host.
- Make agent contributions trustworthy for daily use (checkpoint/rollback + review gate).

## Scope — IN
- LiveKit voice rooms scoped to the workspace: push-to-talk, per-user mute, talking indicators (no video).
- Group + DM text chat (threaded, Yjs-backed) with code-snippet and file/line embeds.
- In-UI git: branch, stage, diff, commit, push to the bundled server, with agent commit attribution.
- Checkpoint / one-click rollback of an agent's changes; branch-aware diff review + in-app merge gate.
- Shared dev-server preview pane (edit → running app).
- OIDC / BYO-IdP auth and optional Postgres for teams; roles per workspace.
- Hardened self-host: single compose (web + server + LiveKit), one-page docs, backup/restore.

## Scope — OUT
- Multiple agents (→ v1.5). Forge UI, scale-out (→ v2.0).
